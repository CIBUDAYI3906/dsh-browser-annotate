# Changelog

## 0.1.0 — 2026-11-23

### Added
- Click to select one element in the shipped right-Sidebar browser (Desktop).
- Hold and drag a marquee to select a batch; nested elements collapse to the outermost region (dialog, card group, toolbar).
- A picker icon in the Browser toolbar and in the HTML document-preview header.
- HTML preview action: serve the local file over a token-guarded loopback server, open it in Browser, and start annotation automatically.
- Host route delivers the selection to the current session's agent.

### Notes
- Desktop only: the Web Browser is a cross-origin iframe and cannot be inspected.
